# DO2_LinuxNetwork — сети Linux

Учебный проект DevOps-трека Школы 21. Настройка сетей на стенде из виртуальных машин: от расчёта адресации до NAT и SSH-туннелей.

Сдан на 140% — выполнено дополнительное задание.

## Что сделано

- **Адресация** — расчёт адреса сети, перевод масок между префиксной, десятичной и двоичной записью, границы диапазона хостов, разделение публичных и частных адресов (RFC 1918), выбор допустимого шлюза
- **Статическая маршрутизация между двумя машинами** — маршрут вручную через `ip route` и постоянный через netplan
- **Замер пропускной способности** канала между узлами (iperf3)
- **Сетевой экран** — скрипт на iptables: правила для ICMP, открытие портов 22 и 80; разбор двух стратегий (запрет-потом-разрешение против разрешения-потом-запрета); поиск не отвечающего на ping узла через nmap
- **Стенд из пяти машин** — три рабочие станции и два маршрутизатора, три сети: адресация по схеме, включение `ip_forward`, маршруты по умолчанию и статические маршруты между роутерами
- **Диагностика трафика** — traceroute с разбором механики TTL по дампу на маршрутизаторе, tcpdump, поведение ICMP при недоступном адресе, правило longest prefix match
- **DHCP** — сервер `dhcpd`: пул выдачи, шлюз, DNS, жёсткая привязка адреса по MAC, обновление аренды
- **NAT** — SNAT для выхода внутренней сети наружу и DNAT (проброс порта 8080 на веб-сервер внутри сети), проверка через telnet
- **SSH-туннели** (дополнительное задание) — local и remote port forwarding к серверу, слушающему только localhost

## Стек
