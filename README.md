# School 21

## Проекты DevOps-трека

Учебные проекты DevOps-ветки Школы 21. В каждой папке - описание проекта, а также отчёт со скриншотами или исходный код, в зависимости от того, что сдавалось.

| Проект | Тема | Результат |
| --- | --- | --- |
| [DO1_Linux](DO1_Linux) | Установка и основы администрирования Linux | 100% |
| [DO2_LinuxNetwork](DO2_LinuxNetwork) | Сети Linux: маршрутизация, iptables, DHCP, NAT | 140% |
| [DO3_LinuxMonitoring_v1_0](DO3_LinuxMonitoring_v1_0) | Bash-скриптинг, сбор информации о системе | 100% |
| [DO4_LinuxMonitoring_v2_0](DO4_LinuxMonitoring_v2_0) | Мониторинг: Prometheus, Grafana, свой экспортёр | 143% |

Проценты выше 100 - выполненные дополнительные задания.

### Стек по треку

Ubuntu Server · systemd · netplan · iproute2 · iptables · dhcpd · tcpdump · nmap · iperf3 · OpenSSH · nginx · bash · awk/sed · Prometheus · Grafana · Node Exporter · GoAccess

Все проекты выполнены индивидуально. В репозитории опубликована только собственная работа - отчёты и скриншоты. Тексты учебных заданий и методические материалы Школы 21 не публикуются.
