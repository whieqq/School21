# DO1_Linux - установка и основы администрирования Linux

Учебный проект DevOps-трека Школы 21. Развёрнут Ubuntu Server 24.04 LTS без графической оболочки в VirtualBox и настроен с нуля до рабочего состояния.

Сдан на максимальный балл (100%).

## Что сделано

- **Пользователи и права** - создание учётной записи, группы, настройка sudo
- **Сеть** - hostname, часовой пояс, получение адреса по DHCP и перевод интерфейса на статическую конфигурацию (IP, шлюз, DNS) через netplan, проверка связности
- **Обновление системы** и синхронизация времени по NTP (`timedatectl`)
- **SSHD** - установка, автозапуск, перенос на нестандартный порт 2022, проверка слушателя через `netstat` и процесса через `ps`
- **Диагностика ресурсов** - `top`, `htop` (сортировка, фильтрация, поиск процессов), `fdisk`, `df`, `du`, `ncdu`: разбор занятости диска по каталогам
- **Системные журналы** - `dmesg`, `syslog`, `auth.log`: поиск событий авторизации и перезапуска служб
- **CRON** - периодическая задача, подтверждение выполнения по логам, управление списком заданий

## Стек

Ubuntu Server 24.04 LTS · VirtualBox · systemd · netplan · OpenSSH · cron · vim / nano / micro

## Структура

```
report.md   - отчёт по проекту: что делал, вывод команд, снятые показатели
images/     - скриншоты терминала, иллюстрирующие каждый шаг
```

## Результат

Основной навык проекта - развернуть и настроить Linux-сервер с нуля, без графической оболочки: работать только в терминале и проверять результат не «на глаз», а выводом команд.
